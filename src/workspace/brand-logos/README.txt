Official logos that are not in the open icon set can be dropped here and ojo will use them automatically.

Name each file after the service's id, for example:
  prime.svg  hotstar.svg  chatgpt.svg  canva.svg  wynk.svg  granola.svg  googleone.svg  adobe.svg  microsoft365.svg

SVG, PNG or WebP all work (square or nearly square, transparent background looks best).
After adding files, rebuild ojo. (People using the installed app can also add a logo to any bill with "Upload logo" in the bill form.)
The ids are listed in src/workspace/brands.jsx.
